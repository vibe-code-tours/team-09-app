# Mhat Tan (မှတ်တမ်း) Presentation Script (Myanmar)

**Slide 1: Title & Introduction**
မင်္ဂလာပါခင်ဗျာ။ ကျွန်တော်တို့ကတော့ Team 09 ဖြစ်ပါတယ်။ ဒီနေ့မှာတော့ ကျွန်တော်တို့ ရေးဆွဲဖန်တီးထားတဲ့ Project လေးဖြစ်တဲ့ "MHAT TAN" (မှတ်တမ်း) ဆိုတဲ့ app လေးဘဲဖြ့စ်ပါတယ်။

**Slide 2: Problem Statement / Hook (ဟိုမေး ဒီမေး)**
ဟုတ်ပြီ
ကျွန်တော်တို့ အားလုံး  နေ့စဉ်ဘဝမှာ အစည်းအဝေးတွေလုပ်တဲ့အခါ ဖြစ်ဖြစ် ၊ စာသင်ခန်းထဲမှာဖြစ်ဖြစ် Note တွေကို လက်နဲ့လိုက်ပြီး ချရေးရတာ တွေအခုထိ လုပ်နေရတုန်းဘဲလား ။ ဟုတ်ပြီ ဒါဆိုရင် စကားလေးပြောလိုက်ရုံနဲ့ ကိုယ်ပြောတဲ့အကြောင်းအရာတွေကို အလိုလို မှတ်ပေးသွားတဲ့ နည်းပညာမျိုး သာရှိရင် ပိုကောင်းမယ်လို့ မထင်ဘူးလား ။ 

**Slide 3: Solution (Mhat Tan ရှိတယ်)**
ဒါဆိုရင်တော့ ကျွန်တော်တို့ရဲ့ "Mhat Tan" ဆိုတဲ့ App လေး ရှိတယ် ဗျ။ 
ဒီ app လေးမှာဆိုရင် စကားလေးပြောလိုက်ရုံနဲ့ အလိုလို Note မှတ်ပေးတာတွေ။ အထူးသဖြင့် Myanmar Language (မြန်မာဘာသာစကား) ကိုပါ note မှတ်ပေးနိုင်တဲ့အတွက်ကြောင့် မြန်မာလူမျိုးတွေအတွက် အများကြီး အဆင်ပြေစေမယ်လို့ ယုံကြည်ပါတယ်။

**Slide 4: Live Demo**
ကဲ... ဒါဆိုရင် ကျွန်တော်တို့ရဲ့ Mhat Tan App လေး လက်တွေ့မှာ ဘယ်လိုအလုပ်လုပ်လဲဆိုတာကို Live Demo လေးနဲ့ အတူတူ ကြည့်ရှုလိုက်ရအောင်ခင်ဗျာ။
*(Live Demo ပြသရန်)*

**Slide 5: Tech Highlight**
*(Demo ပြီးနောက်)* 
ကျွန်တော်တို့ App ကိုတော့ ...
    ၁။ **ElevenLabs Scribe v2:** မြန်မာစကားပြောကို စာသားအဖြစ် အတိကျဆုံးနဲ့ အမြန်ဆုံး ပြောင်းလဲပေးနိုင်ဖို့ ဒီ Speech-to-Text engine ကို အသုံးပြုထားပါတယ်။
    ၂။ **AI Auto-Categorization:** မှတ်သားလိုက်တဲ့ စာသားတွေကို AI ကနေ ဖတ်ပြီး Money, Feelings, Work စတဲ့ Category (၆) မျိုးထဲကို အလိုလို ခွဲခြားပေးသွားမှာပါ။
    ၃။ **Local-First (SQLite):** User တွေရဲ့ Data ကို ဖုန်းထဲမှာပဲ လုံခြုံစွာ သိမ်းဆည်းပေးထားတဲ့အတွက် အင်တာနက်မရှိဘဲ Offline လည်း အသုံးပြုနိုင်မှာ ဖြစ်ပါတယ်။
    ၄။ **Full-Text Search (FTS5):** ကိုယ်မှတ်ထားတဲ့ Note တွေကို မြန်မာလို အမြန်ဆုံး ပြန်ရှာနိုင်ဖို့ FTS5 နည်းပညာကို အသုံးပြုပြီး တည်ဆောက်ထားပါတယ်။


**Slide 6: Future Plans (ဘာတွေဆက်လုပ်ဖို့ရှိလဲ?)**
future မှာ ဘာတွေလုပ်ဖို့ရှိလဲဆိုရင်တော့  -
၁။ **User Accounts တွေချိတ်ဆက်ဖို့:** အသုံးပြုသူတွေအနေနဲ့ ကိုယ်ပိုင် အကောင့်တွေနဲ့ ဝင်ရောက်အသုံးပြုနိုင်အောင် လုပ်ဆောင်သွားပါမယ်။
၂။ **Cloud Sync:** Cloud sync စနစ်ကို အသုံးပြုပြီး device တွေအကုန်လုံးမှာ အလွယ်တကူ ချိတ်ဆက်ရယူနိုင်အောင် ပြုလုပ်သွားပါမယ်။
၃။ **Money Tracking:** နောက်ဆုံးအနေနဲ့ ငွေကြေးသုံးစွဲမှုတွေကိုပါ မှတ်သားနိုင်မယ့် Money tracking စနစ်ကိုပါ ရလာအောင် ထည့်သွင်းသွားဖို့ ရည်ရွယ်ထားပါတယ်။

**Slide 7: Outro**
နောက်ဆုံး အနေနဲ့ ပြောရရင် ဒီ APP ဟာဆိုရင်တော့ v1 နဲ့ အညီ ကိုယ် မှတ်ထားချင်တာတွေကို မှတ်လို့ ရမယ် ၊ record သွင်းပြီးတော့ ပါမှတ်လို့ရမှာဖြစ်ပါတယ်။  နောက်ပ version တွေမှာလည်း ဒီ့ထက်ကောင်းတာတွေလာဖို့ရှိပါသေးတယ် ။

ဒီလို app တစ်ခု ကို ကျွန်တော်တို့  အဖွဲ့ဝင်တွေဖြစ်တဲ့  Thet Naing Lin, Ant Htoo Aung နဲ့ Min Tay Za တို့ က ရေးသားခဲ့တာဖြစ်ပါတယ်။  
အခုလို အချိန်ပေးပြီး ကြည့်ရှုပေးကြတဲ့အတွက် အားလုံးကို ကျေးဇူးအများကြီးတင်ပါတယ် ခင်ဗျာ။
