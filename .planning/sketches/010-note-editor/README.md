# Sketch 010: Note Editor

## Design Question
How should the note editor look — with markdown view/edit toggle, category picker, pin button, and audio player?

## How to View
open .planning/sketches/010-note-editor/index.html

## Variants
- **A: Clean Minimal** — Simple header with back + save, title input, category/pill tools row, raw markdown textarea. View mode shows rendered markdown below.
- **B: Notion-like** — Toolbar with View/Edit toggle, metadata chips (category, pin, time, audio duration), block-based feel with contenteditable title.
- **C: Writing-focused** — Distraction-free: auto-hiding topbar/footer, centered writing area with title divider, footer pills for category/pin/audio that appear on hover.

## What to Look For
- Does the view/edit mode switch feel natural?
- Is the category picker discoverable but not intrusive?
- Which layout feels best for long-form writing vs quick notes?
- Does the audio player fit without disrupting the writing flow?
