## Design Direction

Vibrant + professional, card-based layout. Primary #E91E63 pink, warm base #F8F7F4. Notion-inspired note editor with toolbar and metadata chips. Simple iOS-style bottom sheet for creation actions. Animated illustration for empty states with dual CTAs.

## Key Decisions

- **Note Editor:** Notion-like toolbar with View/Edit toggle, metadata chips (category, pin, time, audio), contenteditable title
- **Bottom Sheet:** Two-option sheet with icon circles, descriptions, and chevron arrows. Backdrop overlay for dismiss.
- **Empty State:** Animated microphone illustration in primary-colored circle, "No entries yet" copy, Record Voice + Write Note CTAs
- **Theme:** Inter font, 4px spacing base, 14px card radius, warm neutral palette with vibrant accents
