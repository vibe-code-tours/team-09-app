# Sketch 011: Bottom Sheet Menu

## Design Question
How should the floating + button's bottom sheet feel — with options for Record Voice and New Note?

## How to View
open .planning/sketches/011-bottom-sheet-menu/index.html

## Variants
- **A: Simple Two-Option** — iOS-style sheet with handle bar, title, two option rows with icons, descriptions, and chevron arrows. Clean and familiar.
- **B: Rich Cards** — Grid of two large cards with prominent icons, bold titles, and descriptive text. More visual, tap-to-select feel.
- **C: Action List** — Compact list with smaller icons, keyboard shortcut badges, and extra options (Photo, File). Scalable for future actions.

## What to Look For
- Which layout feels most native on Android?
- Is the tap target size comfortable?
- Does the sheet feel dismissible (swipe down, tap backdrop)?
- Which design scales better if more options are added later?
