# Sketch 009: Tab-Integrated Search

## Design Question
Does a tab-integrated search — where search is a dedicated tab with inline results — work best for this app?

## How to View
open .planning/sketches/009-search-tab-integrated/index.html

## Variants
- **A: Card Results** — Entry cards grouped by date (Today, Yesterday, This Week) with category tags and voice badges
- **B: Timeline** — Vertical timeline with dots and connecting lines, chronological flow
- **C: Compact List** — Dense single-line items with icon, title, and meta — maximum results visible

## What to Look For
- Does having search as a tab (not an overlay or stack screen) feel natural?
- Which result format works best — cards with details, timeline with context, or compact for density?
- Is the voice search button (🎤) a useful addition?
- Does the category pill navigation at the top feel intuitive?
