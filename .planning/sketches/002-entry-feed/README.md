# Sketch 002: Entry Feed Layout

## Design Question
How should the timeline/feed of voice entries be displayed on the home screen?

## How to View
Open `.planning/sketches/002-entry-feed/index.html` in a browser.

## Variants

- **A: Card Feed** — Individual cards with left border color for category. Most visual, shows mood and pin status. Familiar card pattern.

- **B: Compact List** — Dense list items with category dots. Shows more entries at once. Good for scanning. Like a to-do list.

- **C: Date-Grouped Timeline** — Entries grouped by date with timeline dots and lines. Strongest temporal context. Journal-like feel.

- **D: Timeline + Cards** — Synthesis: date headers from C + card style from A + timeline dots connecting entries. Best of both worlds.

## What to Look For

1. **Information density** — How many entries can you see at once?
2. **Scannability** — How quickly can you find a specific entry?
3. **Category recognition** — How obvious is each entry's category?
4. **Temporal context** — How clear is when each entry was recorded?
5. **Visual hierarchy** — Do pinned entries stand out? Do today's entries feel fresh?

## States to Test
Use the bottom-left states bar to switch between:
- **Populated** — Multiple entries visible
- **Empty** — No entries yet
- **Search** — Filtering entries
