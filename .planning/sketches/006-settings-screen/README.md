# Sketch 006: Settings Screen

## Design Question
What layout structure feels right for the settings page — including the theme picker (light/dark/system)?

## How to View
open .planning/sketches/006-settings-screen/index.html

## Variants
- **A: iOS Grouped Cards** — Rounded card sections with uppercase section headers, iOS-style grouped layout
- **B: Flat Dividers** — Clean flat list with thin dividers, no card grouping
- **C: Compact Dense** — Tight rows with inline theme picker, more info visible at once

## What to Look For
- Theme picker placement and feel (segmented control works across all variants)
- Information density — how much is visible without scrolling
- Visual weight — cards vs flat vs dense
- Toggle switches and interactive elements
- Overall feel — does it match the rest of the app's "vibrant yet professional" direction?
