# Sketch 007: Search Overlay

## Design Question
Does a Notion-style centered overlay (Cmd+K pattern) feel right for searching across all journal entries?

## How to View
open .planning/sketches/007-search-overlay/index.html

## Variants
- **A: Rounded Modal** — Centered modal with rounded corners, recent searches + quick filters, keyboard hints
- **B: Floating Pill** — Elevated floating pill-shaped modal with extra shadow, more dramatic feel
- **C: Full-Bleed** — Full-screen overlay that slides up from bottom, maximum space for results

## What to Look For
- Does the overlay feel natural on mobile, or does it feel like a desktop pattern forced onto a phone?
- Is the search input prominent enough when the overlay opens?
- Do the recent searches and quick filters provide useful shortcuts?
- Does the cancel/dismiss interaction feel right?
