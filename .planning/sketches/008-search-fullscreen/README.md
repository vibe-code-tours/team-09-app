# Sketch 008: Full-Screen Search

## Design Question
How should a dedicated full-screen search screen feel — with persistent search bar, filter options, and results organized by date?

## How to View
open .planning/sketches/008-search-fullscreen/index.html

## Variants
- **A: Chip Filters** — Horizontal scrollable filter chips (All, Money, Feelings, Work, Health, Ideas) below the search bar
- **B: Category Tabs** — Tab bar with underline indicator for category filtering, cleaner separation
- **C: Sort + Date Range** — Adds a sort bar with result count and date range controls

## What to Look For
- Does the persistent search bar feel better than an overlay?
- Which filter style works best — chips, tabs, or sort controls?
- Are the entry cards with voice transcript quotes and category tags informative enough?
- Does the date grouping (Today, Yesterday, This Week) help navigation?
