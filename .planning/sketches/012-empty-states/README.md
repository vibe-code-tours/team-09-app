# Sketch 012: Empty States

## Design Question
What should the home screen look like when there are no entries — and how should first-time users be guided?

## How to View
open .planning/sketches/012-empty-states/index.html

## Variants
- **A: Illustration + CTA** — Animated microphone illustration, friendly copy, two clear CTAs (Record Voice / Write Note). Encouraging and action-oriented.
- **B: Minimal Text** — Single icon, short message, one "Get Started" button. Clean and uncluttered.
- **C: Onboarding Steps** — Welcome card + numbered steps (Record → AI categorizes → Review). Educational, guides new users through the flow.

## What to Look For
- Does the empty state feel inviting or barren?
- Is the call-to-action clear enough to drive the first interaction?
- Which approach works best for users who may not read much English?
- Does the onboarding version feel helpful or overwhelming?
